# 小轩论坛

一个零依赖的实时论坛 / 聊天应用（公共群聊 + 私聊），纯 Node.js 单文件服务端，无需任何 npm 依赖。

> 本仓库为**脱敏版本**：不包含任何用户数据、聊天记录与上传文件。

## 功能

- 文字 / 图片 / 视频 / 任意文件 / 语音消息（录音最长 2 分钟）
- 1MB 分片上传，不限文件大小，按字节精确显示进度，支持断点重试
- 图片 / 视频自定义查看器与播放器（缩放、倍速、全屏），不依赖浏览器原生控件
- 消息撤回（2 分钟内，全员不可见）与删除（不限时，仅自己不可见）
- 消息引用、文字与附件合并发送、链接自动识别并可打开
- 自定义头像与昵称（1~10 位，全站唯一），好友验证开关与申请流程
- 手机 / Pad / PC 三端自适应，锁定缩放，中性灰白配色

## 部署

```bash
# 要求 Node.js >= 16（无任何 npm 依赖，无需 install）
PORT=3000 node server.js
```

服务会自动在项目目录下创建 `data/` 存放数据库与上传文件，建议配合 systemd 或 pm2 常驻，并用 nginx 反代（需开启 WebSocket 升级、`client_max_body_size 0`）。

### 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `DATA_DIR` | `./data` | 数据目录（数据库 + 上传文件） |
| `RECALL_WINDOW_MS` | `120000` | 撤回时限（毫秒） |

## 目录结构

```
server.js          # 服务端（HTTP + WebSocket + 分片上传 + Range 文件服务）
public/index.html  # 页面骨架
public/style.css   # 样式
public/app.js      # 前端逻辑
data/              # 运行时自动生成（不入库）
```
